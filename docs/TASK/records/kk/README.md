# Замер распознавания: казахский и шала-казахский

Пункты 3 и 4 обязательного минимума кейса требуют понимания казахского и смешанной речи.
Здесь — методика и результат, чтобы утверждение не было голословным.

Аудио не публикуется. Сэмплы синтетические, что кейс допускает; воспроизвести замер можно
своими записями, подставив каталог через переменную `SAMPLES`.

## Методика

CER считается против эталонного текста, с которого синтезировались сэмплы. Нормализация
перед сравнением: NFKC, нижний регистр, пунктуация выброшена, пробелы схлопнуты.
Расстояние — Левенштейна по символам, делённое на длину эталона.

```bash
export SAMPLES=/путь/к/сэмплам
export ASR_URL=http://<asr-host>:18000
python3 tools/eval_asr.py
```

## Результат

Дата замера: 2026-09-23. Маршрут выбирался автоматически, `language=auto`.

| Сэмпл | Что в записи | Маршрут | CER |
|---|---|---|---:|
| `azamat_kk_onevoice` | чистый казахский, один голос | `ksc2:whisper-turbo-ksc2-ct2` | **0.000** |
| `azamat_allkk` | русская матрица с казахской вставкой + казахская фраза, синтез тегом kk | `general:whisper-v6-ct2` | **0.057** |
| `azamat_final` | то же, синтез с языковыми спанами | `general:whisper-v6-ct2` | **0.076** |
| `azamat_seam` | два варианта русской фразы + казахская, стык языков | `general:whisper-v6-ct2` | **0.093** |

Для сравнения, на тех же службах чистый русский и английский распознаются без ошибок
(`sample_ru`, `sample_en` из набора речевых служб).

## Эталонные тексты

Русская матрица с казахской вставкой — `айтпақшы` внутри русской фразы:

> Здравствуйте Азамат! Вы айтпақшы что-то говорили про плохое качество генерации на казахском?

Чистый казахский:

> Мен енді қазақша осылай сөйлей аламын, керек болса нақты уақытта да!

## Что видно из ошибок

Деградация возникает **на стыке языков**, а не внутри каждого языка по отдельности:

- `айтпақшы` → `Айтпақши`, `Айтпахшы` — казахская вставка в русской фразе теряет огласовку;
- `про плохое качество генерации` → `про плохое каштар генерационно` — участок сразу после
  вставки разрушается сильнее самой вставки;
- `керек болса` → `Терек болса`, `Мен енді` → `Мин енды` — на переходе в казахскую фразу
  первые слова искажаются.

Практический вывод для протокола: поручения формулируются развёрнуто и обычно целиком на
одном языке, поэтому CER такого порядка на извлечение ответственного и срока не влияет.
Страдают отдельные слова на границе переключения.

## Границы замера

- Четыре сэмпла, синтетическая речь, короткие фразы. Это проверка работоспособности, а не
  бенчмарк.
- Реальная телефонная речь с фоновым шумом и перебиваниями не замерялась.
- Один диктор. Разброс по голосам и диалектам не оценивался.
