# DESIGN.md — front

## Mode

**Operate** (по steering: scanability и консистентность важнее выразительности).
Инструмент обработки записей, не лендинг.

## Visual world

- Светлая институциональная тема по референсу sk.kz (Самрук-Қазына):
  белые карточки на бумажном фоне `paper` (#faf9f7), бордеры `line` (#e8e6e3).
- Navy — фирменная основа: шапка `navy-800` (#1b3351) с бронзовой линией
  снизу, заголовки и основная кнопка navy, ссылки `navy-600` (#00305d).
- Бронза — акцент референса (#b29d8a / #9d7f65): короткое подчёркивание
  заголовков секций, иконки, hover-состояния, скроллбар, выделение текста.
- Семантика на светлом фоне: emerald-700 = готово/высокая уверенность,
  amber-800 = предупреждения/низкая уверенность, red-700 = ошибки/просрочено.
- Говорящие — цветные чипы из стабильной палитры (хэш ярлыка → цвет),
  светлые подложки `*-50` с текстом `*-800`, чтобы спикер читался сквозь
  весь транскрипт.
- Шрифт — стек с «PT Sans» первым (как у референса; если не установлен —
  системный sans, сетевых шрифтов нет: сборка в Docker не должна зависеть
  от внешних CDN). Моноширинный — для таймкодов и ID.

## Layout

- Одна колонка, max-w-6xl. Состояния: загрузка → прогресс → результат.
- Результат: саммари и транскрипт в две колонки на desktop, поручения —
  таблицей на всю ширину, предупреждения — плашкой над результатом.
- Печатная версия — отдельный компонент `PrintableProtocol` (скрыт на
  экране, единственный виден при печати): белый фон, таблица поручений.

## QA

Один батчевый проход (desktop + mobile), один батч правок, максимум один
подтверждающий круг. Working demo beats polish.
